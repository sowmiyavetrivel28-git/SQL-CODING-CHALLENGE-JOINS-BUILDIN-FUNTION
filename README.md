 README – SQL Joins & Built-in Functions

 Overview
This document demonstrates the use of SQL Joins and Built-in Functions for retrieving, formatting, and analyzing data from a school database. It covers data combination techniques using joins and common SQL functions used for numeric, string, and date operations.

---

 Features Covered

 SQL Joins
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

 Numeric Functions
- ROUND()
- ABS()
- MOD()

String Functions
- CONCAT()
- LENGTH()
- REPLACE()
- SUBSTRING()
- UPPER()
- LOWER()

 Date Functions
- NOW()
- DATEDIFF()
- DATE_ADD()

---

 Database Tables
- Students
- Courses
- Enrollments

---

Key Learnings
- Combining data from multiple tables using different types of joins.
- Retrieving matching and non-matching records using LEFT and RIGHT JOIN.
- Rounding decimal values using `ROUND()`.
- Calculating absolute values and remainders using `ABS()` and `MOD()`.
- Merging text values using `CONCAT()`.
- Measuring string length using `LENGTH()`.
- Modifying text using `REPLACE()`.
- Extracting specific characters using `SUBSTRING()`.
- Converting text to uppercase and lowercase using `UPPER()` and `LOWER()`.
- Working with dates and time using `NOW()`, `DATEDIFF()`, and `DATE_ADD()`.

---

 Learning Summary
Through this exercise, I learned how to combine data from related tables using SQL joins and apply built-in SQL functions for numeric calculations, string manipulation, and date processing. These concepts are essential for data retrieval, formatting, reporting, and database management tasks.
